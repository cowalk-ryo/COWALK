# COWALK

葛藤と向き合い、人生を動かす — 対人支援・キャリアコーチング

## サイト

GitHub Pages で公開しています。

## 構成

```
.
├── index.html    # サイト本体（1ファイル完結）
├── profile.jpg   # プロフィール写真
└── README.md
```

## 更新方法

`index.html` を編集して main ブランチに push すると、1〜2分で反映されます。

## 申し込みフォーム

Google Forms を使用。リンクは `index.html` 内の `forms.gle` を検索して差し替えてください。
